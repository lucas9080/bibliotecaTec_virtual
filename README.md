## Perfil

- poderá ser criado um perfil, com nome, telefone E-mail e demais informações que estão disponíveis para serem preenchidas.



## Tecnologias empregadas

### Frontend

- Este projeto tem por intuito a concepção em html, css e Javascript puro, para aprendizado e para consolidar de conhecimentos. Após isso, o projeto será reestruturado em React.js.

### Backend

- O projeto será feito em node.js desde sua concepção até melhorias futuras, tendo o framework express.js como base.

- O banco de dados será inicialmente feito em SQlite, podendo ter atualizações futuras.
